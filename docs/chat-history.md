## Питання

1. **Драйвер Postgres.** Пропоную `pg` (node-postgres): найпоширеніший і з явними транзакціями через окреме зʼєднання. Альтернатива — `postgres` (porsager) з запитами через шаблонні рядки.
2. **Міграції.** Пропоную нумеровані `.sql` файли і маленький запускач у нашому CLI: без залежностей і в дусі «без ORM». Альтернативи — dbmate або node-pg-migrate.
3. **Перевірка запитів.** Пропоную JSON schema, вбудовану у Fastify, без нових залежностей. Альтернатива — zod.
4. **Префікс і формат токена.** Пропоную `evk_` + 32 випадкові байти в base64url (від назви проекту envkeep). Підходить?
5. **Захист аудиту.** Права + тригер, як у D-19, чи тільки права?
6. **Postgres для тестів.** Testcontainers (окрема база на кожен прогін, нічого не треба запускати вручну) чи окремий сервіс `postgres-test` у compose?
7. **Порт 5432.** Прибрати з основного `docker-compose.yml`, а для локальної розробки відкривати його через `docker-compose.override.yml`?
8. **Назва змінної з майстер-ключем.** `ENVKEEP_MASTER_KEY`?
9. **Випуск токенів.** Командою в наявному `src/cli` (commander)?
10. **ADR «чому не Vault» — мені потрібні ваші справжні причини.** Чесно кажучи, Vault або його відкритий форк OpenBao закривають багато з того, що нам треба: Transit дає окремий ключ на клієнта, плюс є вбудований аудит. Ось що я можу припустити, підтвердьте або виправте:
    - Vault — ще одна складна система в експлуатації (unseal, оновлення, бекапи) для маленької команди.
    - Ліцензія BSL у Vault.
    - Клієнтам треба показувати історію з purpose по кожному клієнту, а аудит Vault для цього не підходить, тож обгортку над ним однаково довелося б писати.
    - Хмарні менеджери секретів (AWS Secrets Manager, GCP Secret Manager) розглядали?
11. **ADR «майстер-ключ в env».** Який KMS плануєте потім: AWS, GCP чи інший? Від цього залежить розділ про наслідки.
12. **Формат ADR.** Пропоную файли `docs/adr/0001-*.md` з розділами Context / Decision / Alternatives / Consequences, по пів сторінки кожен.

Достатньо відповіді на кшталт «1 ок, 2 ок, 5 тільки права, 10: …». Після цього напишу `design.md` з розділом альтернатив для ключових рішень і чотири ADR.
